# Biblioteca visual — Ética y Seguridad en la Red

Estructura base para crear y organizar infografías y apartados visuales sobre privacidad y ética de datos.

Cómo usar:

- Coloca las imágenes en `assets/img/` y reemplaza las cajas de ejemplo en `biblioteca/index.html`.
- Copia `biblioteca/plantilla.html` para crear nuevos apartados temáticos.
- Personaliza colores y tipografía en `style.css`.
- Añade interactividad en `assets/js/main.js`.

Si quieres que genere ejemplos de infografías SVG o tarjetas imprimibles, dime qué tipo necesitas.
